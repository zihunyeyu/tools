# DNF 试衣间 (Dressing Room) 使用文档

## 概述

DNF 试衣间是一个用于预览 DNF（地下城与勇士）时装搭配的工具。支持多职业、多部位装备组合预览，提供 3D 模型展示、图标管理、套装管理等功能。

## 系统要求

- Python 3.8+
- 依赖库：`numpy`, `PIL` (Pillow), `pydoftools`
- 显示分辨率：建议 1440x900 或更高

## 启动方式

```bash
python dressing_room_optimized.py
```

首次启动时会要求选择 NPK 文件所在目录。

## 主要功能操作

### 1. 选择职业

1. 点击左侧面板 **职业** 按钮
2. 在弹出的对话框中选择职业
3. 等待加载完成（状态栏显示进度）

### 2. 查看时装

1. 点击部位按钮（如：帽子、上衣等）
2. 在右侧网格中浏览时装
3. 点击时装图标进行选择
4. 左侧面板实时显示预览

### 3. 使用图标模式

1. 点击 **模式: 3D** 按钮切换为 **模式: 图标**
2. 网格将显示时装的图标而非 3D 预览
3. 方便快速查找特定图标

### 4. 配置时装图标

#### 4.1 配置标准图标

1. 右键点击网格中的时装
2. 选择 **配置图标**
3. 在对话框中选择 **标准图标** 标签页
4. 点击未使用的图标帧
5. 点击 **保存**

#### 4.2 配置自定义图标

1. 右键点击网格中的时装
2. 选择 **配置图标**
3. 切换到 **自定义图标** 标签页
4. 搜索或选择 IMG 文件
5. 选择图标帧
6. 点击 **设为自定义图标**

#### 4.3 删除图标配置

1. 右键点击已配置图标的时装
2. 选择 **配置图标**
3. 点击 **删除图标** 按钮

### 5. 设置隐藏部位

1. 右键点击网格中的时装
2. 选择 **配置图标**
3. 勾选需要隐藏的部位（如隐藏帽子）
4. 点击 **保存**

### 6. 保存套装

1. 搭配好各部位时装
2. 点击底部 **生成套装** 按钮
3. 输入套装名称
4. 点击确定

### 7. 应用套装

1. 在右侧套装列表中选择套装
2. 点击 **应用整套装扮** 按钮
3. 或使用右键菜单 **应用套装**

### 8. 播放动画

1. 从 **动作** 下拉框选择动画
2. 点击 **播放** 按钮
3. 或使用 **◀ / ▶** 手动切换帧

## 配置文件说明

### 主配置文件

**`avatar_config.json`** - 时装配置数据

```json
{
  "swordman_male": {
    "metadata": {
      "_version": "2.0",
      "_migrated": true
    },
    "items": {
      "coat": {
        "1234": {
          "name": "时装名称",
          "frame": 6,
          "hide_parts": ["cap"]
        }
      }
    },
    "suits": [
      {
        "name": "套装名称",
        "items": {
          "coat": "1234",
          "pants": "5678"
        }
      }
    ]
  }
}
```

### 缓存文件

**`dressing_room_cache.json`** - 用户设置缓存

```json
{
  "npk_dir": "D:/DOF/NPK",
  "theme": "light"
}
```

## 常见问题

### Q: 首次启动无法找到 NPK 文件？
A: 请确保选择的目录包含 `.npk` 文件，通常是 DNF 客户端的 `sprite` 或 `avatar` 目录。

### Q: 图标显示为空白？
A: 该时装可能未配置图标映射，右键点击时装选择 **配置图标** 进行设置。

### Q: 切换职业后数据未刷新？
A: 点击 **职业** 按钮重新选择当前职业，或重启程序。

### Q: 如何清除缓存？
A: 删除程序目录下的 `icon_cache` 文件夹和 `dressing_room_cache.json` 文件。

## 性能优化建议

1. **首次加载** - 程序会构建 IMG 索引，可能需要一些时间
2. **图标缓存** - 图标会自动缓存到 `icon_cache` 目录，加速后续加载
3. **内存使用** - 大量时装预览时会占用较多内存，建议定期重启程序
4. **后台预加载** - 切换职业后会后台预加载图标，等待完成后再操作

## 高级功能

### 1. 同系列装扮自动命名

在配置图标对话框中，点击 **应用同系列装扮** 按钮可以：
- 自动识别同系列时装（多调色板变装）
- 为系列内所有时装应用统一名称格式（如：`时装名称[款式1]`）
- 统一设置隐藏部位

### 2. 图层高级控制

#### 隐藏部位设置
某些时装（如某些帽子）会自动隐藏其他部位（如头发）：
1. 右键点击时装 → **配置图标**
2. 在 **隐藏部位** 区域勾选需要隐藏的部位
3. 保存后预览时将自动隐藏对应部位

#### 强制显示隐藏部位
- 勾选底部 **强制显示隐藏** 开关
- 被隐藏的图层将强制显示
- 用于查看完整装备效果

### 3. 自定义动画

1. 切换到 **动画** 标签页
2. 输入动画名称
3. 输入帧序列（如：`0-10,15,20-30`）
4. 点击 **加载当前** 使用当前动作帧
5. 调整播放速度
6. 点击 **保存动画**

### 4. 图标管理模式切换

点击 **模式: 3D** 按钮可切换：
- **3D 模式** - 显示时装的 3D 预览缩略图
- **图标模式** - 显示时装的物品图标

### 5. 缺失筛选

点击 **显示: 全部** 按钮可切换：
- **全部** - 显示所有时装
- **仅缺失** - 只显示未配置图标的时装

## 右键菜单功能

### 时装网格右键菜单

右键点击时装网格中的项目：
- **配置图标** - 打开图标配置对话框

### 套装列表右键菜单

右键点击套装列表中的项目：
- **✏️ 修改套装名** - 重命名套装
- **🗑️ 删除套装** - 删除套装

## 数据备份与恢复

### 自动备份
- 配置迁移时会自动创建备份文件
- 备份文件格式：`avatar_config_backup_YYYYMMDD_HHMMSS.json`

### 手动备份
建议定期备份以下文件：
- `avatar_config.json` - 时装配置数据
- `dressing_room_cache.json` - 用户设置
- `icon_cache/` 目录 - 图标缓存（可选）

## 故障排除

### 启动问题

| 问题 | 解决方案 |
|------|----------|
| 程序无法启动 | 检查 Python 版本是否为 3.8+ |
| 缺少依赖 | 运行 `pip install numpy Pillow` |
| 找不到 NPK | 确认 NPK 路径正确，目录包含 .npk 文件 |

### 显示问题

| 问题 | 解决方案 |
|------|----------|
| 界面显示异常 | 尝试切换主题或重启程序 |
| 预览黑屏 | 检查 f/g/h 层处理开关 |
| 图标不显示 | 清除 icon_cache 目录后重试 |

### 性能问题

| 问题 | 解决方案 |
|------|----------|
| 加载缓慢 | 等待后台预加载完成 |
| 内存占用高 | 定期重启程序释放内存 |
| 卡顿 | 减少同时显示的项目数量 |
